Mystic Uploader

A private publishing tool for the owner's own YouTube channels.

Mystic Uploader is a personal, non-commercial tool. It is used by a single person to upload videos to, and read performance statistics for, YouTube channels that he owns and manages. It is not offered to the public and does not access any other person's account.

It uses the YouTube Data API and the YouTube Analytics API only with the channel owner's own explicit permission, granted through Google's standard sign-in screen.
