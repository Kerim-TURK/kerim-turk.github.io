Privacy Policy

Mystic Uploader · Last updated: 27 September 2026

What this application is

Mystic Uploader is a private, non-commercial tool used by one person to manage YouTube channels that he owns. It is not available to the public, and it is only ever authorised by the channel owner himself.

What data it accesses

With the owner's permission, granted through Google's sign-in screen, the application uses:

  • the YouTube Data API, to upload videos, set their titles, descriptions, thumbnails and publishing schedule, and add them to playlists on the owner's own channels;
  • the YouTube Analytics API (read-only), to read performance statistics for those same channels, such as views, watch time and traffic sources.

How the data is used and stored

Data is used only to perform the actions above for the owner's own channels. The access token issued by Google is stored only on the owner's personal computer. No data is sold, shared with, or transferred to any third party, and none is used for advertising.

Mystic Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google account's third-party access settings. Revoking access stops the application from reaching the account immediately.
